## How I work

Software often reports success because a process exited `0`, not because the work
happened. When a program is driving another program, that gap is where most of the
real bugs live, so I check the output rather than the return code.

## Current work

A Model Context Protocol server that lets an AI agent operate Inkscape: editing,
analysing and exporting SVG files, with every result verified against the file it
produced rather than the exit status.
